# Legado Angular

Esta pasta preserva a base Angular original apenas como referência de migração.

- Código-fonte legado: `legacy-angular/src`
- Entrada Angular legada: `legacy-angular/src/main.ts`
- Estilos Angular legados: `legacy-angular/src/styles.scss`

A aplicação ativa do G3-Next é a base React em `src/`.

O pacote `frontend` não instala mais dependências Angular nem expõe scripts Angular. Este material ficou arquivado apenas para consulta histórica durante a migração.

Não crie novas funcionalidades aqui.
